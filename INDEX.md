## 🎯 What This Project Does

### Input
- 5 CCTV camera videos (MP4)
- Store layout data (Excel)

### Processing
1. **Detect customers** in video frames
2. **Track positions** across zones
3. **Calculate metrics** (footfall, dwell time, etc.)
4. **Generate heatmaps** of traffic patterns
5. **Analyze journeys** through the store
6. **Create insights** and recommendations

### Output
- **CSV reports** with detailed data
- **JSON insights** with key findings
- **Visualizations** (charts, heatmaps)
- **HTML dashboard** with interactive report

## 🛠️ Customization

### Adjust Detection Sensitivity
Edit `config.json`:
```json
{
  "video_processing": {
    "detection_threshold": 25,
    "min_contour_area": 500
  }
}
```

### Change Zone Definitions
Edit `main.py`:
```python
zones = {
    'CAM 1': {'name': 'Entrance', ...},
    'CAM 2': {'name': 'Cosmetics', ...}
}
```

### Customize Reports
Edit `report_generator.py` to add custom sections
